Pico­Term

User manual

A terminal program for the TS-2068 and the TS-Pico v3 card. The card's WiFi modem runs Zimodem, and PicoTerm uses it to reach telnet BBSes: ANSI color and box drawing, 32 or 64 columns (80 with PicoVideo), a phonebook, and XMODEM downloads to the SD card.

PicoTerm 0.6 © 2026. Written in Z80 assembly for the TS-Pico v3 card.

Built on Bo Zimmerman's Zimodem, the TS-Pico firmware and ROM, and the TS 2068 Technical Manual's Video Mode Change Service (as Zebra's OS-64 uses it). The CP437 font is PicoVideo's: Bm437_ACM_VGA_8x8 from VileR's Ultimate Oldschool PC Font Pack (int10h.org), CC BY-SA 4.0.

This manual was written from the program itself. Its screenshots come from PicoTerm's own code run on a model of the 2068 with a simulated modem and BBS, so the BBS screens are examples.

Keys in this manualCAPS is CAPS SHIFT and SYM is SYMBOL SHIFT. BREAK is CAPS+SPACE; it opens PicoTerm's menu, and in any PicoTerm screen it goes back one step.

01What you need

  • A TS-2068 with the TS-Pico ROM 2.3 or later.
  • The TS-Pico v3 card, with firmware that has the TS2050 modem emulation (the 8251 at ports $73 and $77), and Zimodem on the card's ESP32. The card's modem has to be in Hayes mode. PicoTerm switches it there itself where the firmware allows.
  • A WiFi network the card can join. PicoTerm can scan for one and join it (section 9).
  • An SD card in the TS-Pico, for picoterm.cfg (your settings and phonebook) and for downloads.
  • Optional: PicoVideo, for 80 columns and for color in 64 columns, on its HDMI output.
A real TS2050?PicoTerm is written for the TS-Pico's modem. It doesn't pulse-dial, and it doesn't watch the TS2050's carrier line, so it won't drive an original 300-baud TS2050. Use MTERM for that.

02Loading PicoTerm

picoterm.tap holds a one-line BASIC loader and about 15 KB of machine code, which loads at 34816 (8800h).

  1. Copy picoterm.tap to the SD card's /TAP folder.
  2. Type LOAD "tpi:picoterm.tap" ENTER to mount it.
  3. Type LOAD "" ENTER. The loader runs by itself.

What happens at start-up

  1. PicoTerm reads picoterm.cfg from the card's current folder, if there is one, and sets up the screen in its column mode.
  2. It puts the card's modem in Hayes mode (tpi:modem hayes).
  3. It resets the 8251, which starts the card's ESP32.
  4. It sends AT once a second until Zimodem answers OK (up to about 12 s; Zimodem's banner may show first), then your init string (ATE1V1X1Q0) and the telnet terminal type (AT&S"41=ANSI").
  5. It turns on flow control: ATF1, then tpi:modem flow on. Older firmware refuses, and PicoTerm carries on without.
  6. It shows Modem ready. You see everything the modem says. If something is missing, a message says so and PicoTerm carries on (section 12).
Hayes mode staysThe TS-Pico saves the modem's mode in config.ini, so the card stays in Hayes mode after you quit. Before loading MTERM or another TS2050 program, type SAVE "tpi:modem 2050".
MemoryThe loader does CLEAR 34815. PicoTerm also opens the second display file with the ROM's Video Mode Change Service, as OS-64 does, which moves BASIC up to 7B00h. It stays open after you quit, so BASIC has about 7 KB less room until you reset.

03Your first call

Once the modem is ready, everything you type goes to it. Zimodem echoes your typing and answers in words (OK, CONNECT, NO CARRIER), like a Hayes modem.

  1. Join your WiFi, once: BREAK, then W (section 9).
  2. Dial a host by typing its address in quotes: ATDTX"bbs.example.com:23" ENTER. The T asks for telnet, which most BBSes want, and the X turns on flow control. ATDX"…" is a raw TCP port.
  3. Zimodem answers CONNECT. From now on everything you type goes to the BBS.
  4. To hang up: BREAK, then H. If the BBS hangs up first, you see NO CARRIER.

Put the hosts you use in the phonebook (section 8) and dial them with one key; it adds the X itself.

Why the XWhen the BBS sends faster than the 2068 draws, the card tells Zimodem to pause and go on (XOFF, XON). Zimodem obeys only on a call dialed with X; without it a fast host can overrun the card. It needs firmware with tpi:modem flow.

Control keys

Press CAPS and SYM together, let go, then press a letter: PicoTerm sends it as a control key. CAPS+SYM, C sends Ctrl-C. Pressing CAPS+SYM twice cancels it. It works for the letters and [ \ ] ^ _. With flow control, Zimodem keeps Ctrl-S and Ctrl-Q for itself.

05The terminal

PicoTerm has three emulations. It uses ANSI unless you choose otherwise in Settings or in a phonebook entry, and it tells Zimodem which one to report to telnet hosts.

EmulationWhat it understands
ANSIFor BBSes: a VT100 subset with color, as BBS software expects of "ANSI-BBS".
  • Cursor moves, positioning, save and restore.
  • Erasing; inserting and deleting lines and characters.
  • A scrolling region.
  • Colors with bold, blink and reverse.
  • It answers the cursor-position question, which BBSes use to find the screen size, and identifies itself as a VT100.
VT52The standard set: cursor moves, home, ESC Y addressing, erasing, reverse line feed, identify.
TTYText and control codes only; escape sequences show as text.

In every emulation PicoTerm handles BEL, a short tone on the AY; BS; Tab, every 8 columns; LF; CR; and FF, which clears the screen. Text wraps as on a VT100: a character in the last column leaves the cursor there, and the next starts a new line.

Color and characters

ANSI's eight colors become the 2068's. Bold is BRIGHT, blink is FLASH (or not, in Settings), and reverse swaps ink and paper. BRIGHT lights the whole cell, so bold text on a colored background brightens the background too.

PicoTerm uses the PC's CP437 characters, as PicoVideo does for 80 columns, so box lines, shading and accented letters look as BBS authors meant.

0632, 64 and 80 columns

CAPS+9 changes mode, keeping what's on screen. Settings C picks the mode PicoTerm starts in.

80PicoVideoPer character, on HDMI. The 2068's own video shows nothing useful. Turn on PicoVideo in Settings.

The screen is 24 rows. A line scrolls in about 40 ms in 32 and 80 columns and 100 ms in 64: fast enough for 2400 baud.

09WiFi

BREAK, then W, while offline. Zimodem scans (ATW) and PicoTerm lists up to 16 networks.

  1. Choose one with the arrows and press ENTER, or M to type a name that isn't listed. R scans again.
  2. Type the password (it shows as stars) and press ENTER. PicoTerm sends ATW"name,password" and waits up to 20 s.
  3. If it worked, Y makes it the default (AT&W): Zimodem joins it by itself from then on.
Commas and quotesZimodem's ATW"name,password" can't carry a comma or a " in either part.

picoterm.cfg

S writes picoterm.cfg in the SD card's current folder; PicoTerm reads it at start-up. It's plain text: emul=2 (0 TTY, 1 VT52, 2 ANSI), cols=1 (0 is 32, 1 is 64, 2 is 80), picovideo, ink64, bs (8 or 127), echo, enter, blink, bell, init, and a line per phonebook entry:

phone=Test BBS|bbs.example.com:23|1|2|0|8|0

That's the name, host, telnet, emulation, columns, backspace and echo. Lines PicoTerm doesn't understand are skipped.

11Downloading files

PicoTerm receives with XMODEM, CRC or 1K, with checksums for older senders. The file goes to the TS-Pico's SD card.

  1. On the BBS, choose the file and XMODEM.
  2. BREAK, X, and a name for the file (download.bin). PicoTerm asks before replacing a file.
  3. The window counts blocks, bytes and errors. Damaged blocks are asked for again.
  4. Strip ^Z padding? XMODEM pads the last block with 1Ah. Y for text; N for programs and binaries.
  5. PicoTerm saves the file and shows its size.

BREAK cancels and tells the BBS. In stock 64-column mode, PicoTerm uses 32 columns during the transfer: the file is held in the 64-column screen's memory.

In this versionDownloads are received into memory first: at most 6,912 bytes. The file is saved as SAVE "f:name" CODE saves it, so it starts with a 128-byte +3DOS header. LOAD "f:name" CODE loads it back; on a PC, cut the first 128 bytes. A planned TS-Pico firmware addition should lift both limits.

12Messages and problems

You seeIt means, and what to do
Modem ready.Zimodem answered. Type or dial.
This TS-Pico has no tpi:modem.Older card firmware. Set the card's modem to Hayes mode yourself (see the TS-Pico manual), or update.
No modem: the 8251 isn't ready.Nothing at $73/$77 within 5 s: no v3 card, the modem off, or no modem firmware. PicoTerm runs; modem keys are dropped.
No answer from the modem.No OK in about 12 s. Check the modem is in Hayes mode (TS2050 mode hides Zimodem's replies), then type AT ENTER.

NO CARRIERThe host hung up.

Couldn't save the settings.No TS-Pico or SD card, or the card refused.

Too many errors. Canceled.Ten bad blocks in a row. Try again.

13Limits

  • Downloads only, and at most 6,912 bytes: no upload, YMODEM or ZMODEM, and no capture to a file.
  • No scrollback. Text that scrolls off the top is gone.
  • 24 rows. BBSes that assume 25 lose the bottom line.
  • Color: no bright background on its own; 64 columns on a stock 2068 has one color pair.
  • Keyboard: the symbol keys follow the Spectrum's legends, which the 2068 mostly shares; the tables in section 4 are what PicoTerm does.
  • Screen width: PicoTerm can't tell a telnet host your width itself. Most BBSes ask, or measure it with the cursor-position question, which PicoTerm answers.
  • The modem: the TS-Pico's, in Hayes mode, with its 8251 emulation. Not a stock TS2050.
  • Ctrl-S and Ctrl-Q don't reach the host on a call with flow control.
